## 1. The one-line claim

A DecisionInfluenceReceipt is the trace **a governed influence leaves**: *what signal was exposed → which subset was used → what action it changed → whether the outcome beat a baseline → under whose authority.* anneal's shipped `RetrievalReceipt` is the **recall-rooted projection** of this object (a memory influencing a claim). The vagus efferent gate produces the **action-rooted projection** (a proposal influencing a world-action). Same object; different faces populated.

**Why this matters for the stack:** the vagus constitution is `govern-not-trust` compiled into a runtime invariant — the efferent membrane is the **gate**. The receipt is **the trace the gate leaves.** Membrane and receipt are one seam viewed twice. So defining the receipt once is the same act as making the governed loop legible — and it is what keeps the four parallel build fronts from each inventing a divergent trace shape (the fossil-trap).

## 3. The faces (each surface's slice + role)

- **anneal Slice-C — CONSUMER (recall face).** Populates the recall fields (`query_*`, `exposed[]`, `cited_used`, `provenance_spans`, `outcome_signal`, `hwm/pv`). The **`baseline` is anneal-exclusive** — it comes from the §9.2 A/B replay harness (same query, N recall paths), not from the receipt's own writing. Leaves the action-face (`gate`, `authority_scope`) null. This is the **shipped** face (`RetrievalReceipt` v2, durable at `state/retrieval_receipts.jsonl`).
- **vagus efferent gate — PRODUCER (action face).** When the membrane gates a proposal, it emits a receipt: the proposal's afferent input is `exposed[]`/`provenance_spans`, the human decision is `gate`, the authorization is `authority_scope`, the fired action is `downstream_claim_or_action_id`, the result is `outcome_signal`. **The gate emits the fields it already has at the moment of gating — it does NOT build a receipt system** (anti-grab-bag: the schema lives at anneal; the vagus populates its slice). `actor_first_estimate` carries the human's read when the gate routed through a human-present confirm. **For a roundtable-afferent proposal-set** (the `spore-157` experiment shape), each `exposed[]` item carries `source="afferent"` + `producer=<lineage>` so the per-lineage dissent SURVIVES into the trace — the survival the experiment proved is the moat (not diversity-gain); the human's collapse (`cited_used`/`gate`) over that kept, lineage-tagged set is the fan-in.
- **Bridge / FleetView — RENDERER.** Reads ALL fields; renders the receipt corpus as **queryable topology, not a dashboard, not a firehose** (06-22 sharpening + daemon `91ada5c0`/`8b4eb8b6`). The render contract is **constraint-exposing**: surface the `gate=denied` and divergent verdicts (`8b4eb8b6` "surface dissent, not average"), the stale `outcome_signal`s, the `authority_scope` boundaries across N seats. FleetView **renders receipts; it never authors them.**
- **FlowPoker — BINDER.** `actor_first_estimate` (the read) → `downstream_claim_or_action_id` (forbidden/permitted action) → `outcome_signal` (exact-vs-modeled feedback). The read-trainer is a receipt producer with a human-first-estimate at its center (`spore-114` calibration split lives here).
- **precedent registry (augmentation_harness) — COMPILER.** Uses `authority_scope` + `gate` + `outcome_signal` as the trace that lets an adopted precedent compile into harness policy **without becoming CLM/legaltech** (daemon `d61a2d01`).
